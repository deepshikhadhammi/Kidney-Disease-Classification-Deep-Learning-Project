# Kidney-Disease-Classification-Deep-Learning-Project


## Workflows

Follow these steps in order when developing or updating the deep learning pipeline:

1. Update `config/config.yaml`
2. Update `secrets.yaml` (Optional)
3. Update `params.yaml`
4. Update the entity definitions in `src/cnnClassifier/entity/`
5. Update the configuration manager in `src/cnnClassifier/config/configuration.py`
6. Update the components in `src/cnnClassifier/components/`
7. Update the pipeline in `src/cnnClassifier/pipeline/`
8. Update `main.py`
9. Update `dvc.yaml`
